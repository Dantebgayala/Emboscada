# EMBOSCADA ONLINE — versão atualizada

## Regras implementadas
- 8 peças por jogador.
- Movimento de 1 casa na diagonal.
- Centro: captura com 4 inimigos nos lados ortogonais.
- Borda: captura com 3 inimigos nos lados existentes.
- Canto: captura com 2 inimigos nos lados existentes.
- Entrar em uma casa completamente cercada captura imediatamente a peça.
- Vence quem alcançar 7 capturas.

## Rodar
npm install
npm start

## Publicar
O arquivo render.yaml está incluído para implantação no Render.
